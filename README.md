# RKO Platform

Приватная рабочая версия образовательной платформы RKO.

## Текущая версия

- заставка и экран входа;
- тестовый администратор: `admin / admin`;
- тестовый ученик: `student / student`;
- разные приветствия и шапки для ролей;
- пустая основа раздела «Обучение»;
- переход администратора между обучением и основой панели управления;
- вкладки «Структура», «Аккаунты» и «Настройки»;
- возврат к авторизации через «Выйти» без повторной заставки.

> Текущие тестовые данные находятся в клиентском коде и используются только для визуального прототипа. Перед настоящим запуском они будут заменены серверной авторизацией.
