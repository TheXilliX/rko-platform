# RKO Platform

Приватная рабочая версия образовательной платформы RKO.

## Текущий этап

- утверждён прототип экрана авторизации;
- зафиксирована визуальная палитра;
- проектируется меню ученика;
- проектируется панель администратора;
- серверная авторизация и база данных пока не подключены.

> Важно: текущий экран входа — визуальный прототип. Проверка логина и пароля в браузере не является защитой и будет заменена серверной авторизацией до публикации настоящего курса.
